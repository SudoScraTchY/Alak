Signature Component

The Ticket Stub

Why settle for generic rounded cards? Alak treats promo codes like physical coupon stubs: torn edges, monospaced clarity, and visual expiry tracking.

Physical Paper, Settled on Your Desk

Most apps drown notifications in a wall of homogenous rounded cards. Alak borrows directly from the tactile shape of a physical ticket:

  • Die-Cut Perforation: A perforated tear notch evoking a ticket stub torn from a physical coupon roll.
  • JetBrains Mono Code: Zero character confusion between 0 and O, 1 and l.
  • Draining Expiry Bar: A 3px bar visually draining towards midnight so you never miss a flash deal.
  • One-Tap Copy & Feedback: Copies clean text directly to clipboard with instant confirmation.

Technical Architecture

The 3-Tier Classification Pipeline

Engineered for instant speed and zero cloud dependency. 99% of work finishes in under a millisecond with 0 battery waste.

Tier 1 · Instant Rule Engine

Deterministic Rules

Sub-millisecond Aho-Corasick

Evaluates incoming notifications with log-odds concept scoring and multilingual extractors. Resolves categories safety-first (Security > Money > Work > Orders > Offers).

  • Average Latency < 0.5 ms
  • RAM Footprint Negligible
  • Network Calls 0 (Always)
Tier 2 · Adaptive Classifier

On-Device Learning

Online AdaGrad Hashed Features

Learns from your corrections on-device. Feature hashing guarantees that no raw personal text is ever stored for training weights.

  • Weight File 2.4 MB (Private)
  • Update Speed < 3 ms
  • Adaptation Instant
Tier 3 · Small Language Model

User-Triggered SLM

Tap-Only BYO Model

Optional local AI: runs strictly when you tap 'Explain' or 'Summarize'. Uses GGUF / LiteRT models imported by you. Never runs in background.

  • Execution Mode Manual Tap Only
  • Constraint GBNF Grammars
  • Cloud Leak Impossible
Privacy by Construction

Verifiable, Not Promised

We don't ask you to trust a privacy policy. Privacy is hardcoded into the architecture and verified automatically in CI.

Zero Network Capability

Neither android.permission.INTERNET nor ACCESS_NETWORK_STATE is declared. CI privacy-guard halts builds if any network API is detected.

No Analytics, Ads, or Crash SDKs

No Firebase, Facebook, Sentry, AppCenter, or telemetry SDKs exist anywhere in the dependency graph.

SQLCipher 256-bit AES Encryption

All stored notifications and extracted entities reside in an encrypted database with full-text search.

Zero OTP / 2FA Persistence

Verification codes, banking passwords, and 2FA tokens are classified as security and immediately discarded from persistent storage.

Two Scripts, One Product

Persian & English as Equals

Persian is not an afterthought translated from English. Both scripts receive native typographic treatment and dedicated language features.

  • Native Jalali (شمسی) calendar engine with golden-table tests (1400–1420).
  • Full Arabic/Persian character normalization (ی/ي, ک/ك, and ZWNJ نیم‌فاصله).
  • Persian scale words (هزار, میلیون) and currency conversions (ریال / تومان).
  • Experimental Finglish (fa-latn) extension pack with precision guard rails.
